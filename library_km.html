អំពីបណ្ណាល័យនេះAbout this library

🎯 គោលបំណង / Purpose

បណ្ណាល័យនេះ ជួយឱ្យកុមារគ្រប់រូប អានសៀវភៅឌីជីថលដែលមានសំឡេងបាន។ ដំណើរការក្រោមសន្ធិសញ្ញា Marrakesh។This library operates under the Marrakesh Treaty to provide accessible digital books for children with reading difficulties, including those from disadvantaged backgrounds.

🧒 សម្រាប់អ្នកណា? / Target users

កុមារគ្រប់រូបដែលត្រូវការការគាំទ្រក្នុងការអាន — រួមមានកុមារពិការ កុមារក្នុងគ្រួសារក្រីក្រ និងកុមារនៅតំបន់ឆ្ងាយ។All children who need reading support — including children with disabilities, children from low-income families, and children in remote areas.

របៀបអានសៀវភៅ ក្នុងកម្មវិធីHow to read the books — reader app guide

1

យកកម្មវិធីអានសៀវភៅជាមុនសិន (ឥតគិតថ្លៃ)First, get a free reader app

ជ្រើសកម្មវិធី តាមឧបករណ៍របស់អ្នក។Choose the app for your device.

🤖AndroidColibrio ReaderGoogle Play ⬇ 🍎iPhone / iPadEasyReaderApp Store ⬇ 💻Windows PCThorium ReaderMicrosoft Store ⬇
2

ទាញយកសៀវភៅDownload a book

  1. 👆ចុចប៊ូតុងពណ៌បៃតង “⬇ ទាញយកសៀវភៅ”Tap the green “Download” button
  2. 📥សៀវភៅ (ឯកសារ .epub) នឹងត្រូវរក្សាទុក ក្នុងឧបករណ៍The book (.epub file) is saved on your device
💡 iPhone (Safari): ចុច ⬇ នៅរបារខាងលើ → ចុចឈ្មោះឯកសារ។On iPhone (Safari): tap ⬇ in the address bar → tap the file name.
3

បើកសៀវភៅ ក្នុងកម្មវិធីOpen the book in the app

  1. 📁① បើកកម្មវិធី Files (គ្រប់គ្រងឯកសារ) → ថត DownloadsOpen the Files app → Downloads folder
  2. 👆② ចុចឯកសារ .epubTap the .epub file
  3. 📋③ ជ្រើស Colibrio ReaderChoose Colibrio Reader
  4. ✅④ សៀវភៅបើកហើយ — ចុច ▶ ហើយស្ដាប់!The book opens — press ▶ and listen!
💡 ប្រសិនបើរក Colibrio Reader មិនឃើញ: បើកកម្មវិធី Colibrio Reader ១ ដងសិន ហើយសាកម្ដងទៀត។ ឬ បន្ថែមឯកសារពីក្នុងកម្មវិធី។If Colibrio Reader is not shown: open the app once, then try again — or add the file from inside the app.
  1. 📁① បើកកម្មវិធី Files (ឯកសារ) → Browse → On My iPhone → DownloadsOpen Files → Browse → On My iPhone → Downloads
  2. 👆② ចុចឯកសារ .epub ឱ្យយូរ → ចុច Share (□↑)Press and hold the .epub file → tap Share (□↑)
  3. 📲③ ជ្រើស EasyReader (ឬ “Copy to EasyReader”)Choose EasyReader (or “Copy to EasyReader”)
  4. ✅④ ក្នុង EasyReader ចុច My Books → ជ្រើសសៀវភៅ → ស្ដាប់បានភ្លាម!In EasyReader, tap My Books → choose the book → listen!
💡 ប្រសិនបើរក EasyReader មិនឃើញ: រំកិលបញ្ជី Share ទៅស្ដាំ → ចុច More → បើក EasyReader។
💡 ប្រសិនបើឯកសារមិននៅក្នុង Downloads: សាក iCloud Drive → Downloads ឬ ស្វែងរក “.epub”។Can’t see EasyReader? Scroll the Share list right → More → turn on EasyReader. File not in Downloads? Try iCloud Drive → Downloads, or search “.epub”.
  1. 💻① បើក File Explorer → ថត DownloadsOpen File Explorer → Downloads folder
  2. 📖② បើក Thorium Reader → អូសឯកសារ .epub មកដាក់ក្នុងកម្មវិធីOpen Thorium Reader → drag the .epub file into the app
  3. ✅③ ចុចគម្របសៀវភៅ → ចុច ▶ ហើយស្ដាប់!Click the book cover → press ▶ and listen!
💡 ឬ ចុចប៊ូតុង Import ក្នុង Thorium ហើយជ្រើសឯកសារ .epub។Or use Thorium’s Import button to choose the .epub file.
4
